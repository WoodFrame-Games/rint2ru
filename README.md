# rint2ru — Библиотека Вавилона на цифрах

Поиск осмысленных слов и фраз в случайных числах.

Идея: если каждую букву алфавита заменить её номером, любое слово становится
числом. Например:

```
п   р   и   в   е   т
17  18  10  3   6   20   ->  1718103620
```

Значит, в случайных числах можно искать слова — и находить их. А в достаточно
длинных числах (или их цепочках) — целые фразы. Это и есть «Библиотека
Вавилона» Борхеса, только на цифрах: бесконечный поток случайных чисел
теоретически содержит любой текст.

Репозиторий — это стенд, на котором идея проверена от «найди одно слово за
минуты на питоне» до мультипоточного ассемблерного ядра и локальной ИИ-судьи.

## Кодировка

Алфавит с буквой ё, сквозная нумерация 1..33, буква заменяется своим номером,
коды склеиваются без разделителей:

```
а=1  б=2  в=3  г=4  д=5  е=6  ё=7  ж=8  з=9  и=10  й=11  к=12  л=13
м=14 н=15 о=16 п=17 р=18 с=19 т=20 у=21 ф=22 х=23 ц=24 ч=25 ш=26 щ=27
ъ=28 ы=29 ь=30 э=31 ю=32 я=33
```

Код декодируется неоднозначно (например, `1718103620` — это и `привет`, и
`ажсивет`), поэтому осмысленность чтения проверяют словарём и языковой моделью.

## Что внутри

| Файл | Роль |
|---|---|
| `rs.cpp` | Поиск одного слова (подстроки) в 18-19-значных u64-числах, C++, потоки |
| `rs.asm` | То же на NASM, один поток, голые syscall'ы |
| `rs2.asm` | То же, 2 потока через `clone(CLONE_THREAD)`, без библиотек |
| `cs/Program.cs` | Исходная версия на C# (System.Random + Task) |
| `wordrain.py` | Python-демо: многословные чтения одного числа по словарю |
| `ru.cpp` | Мультисловный поиск в 18-19-значных числах: словарь-слов в хэш-таблице кодов, фильтры (глагол обязателен, ≤2 служебных, без повторов) |
| `ru2.cpp` | То же, но числа — строки произвольной длины (по умолчанию 60 цифр) |
| `ru2dump.cpp` | Экспорт словаря 5+ букв в бинарный `dict.bin` для asm-ядра |
| `ru2asm.asm` | NASM-ядро: 60-значные строки, 2 потока, словарь 5+ букв из `dict.bin` |
| `ru3_stream.cpp` | Поток чисел: числа по 60 цифр склеены в ленту, слова ищутся сквозь стык (хвост 16 цифр), считаются «слова из двух чисел» |
| `ru4_target.cpp` | Прицельный поиск заданной строки в потоке: итерации, время, скорость, ETA |
| `ru5_hunt.cpp` | 24-часовой потоковый хант: журнал лучших фраз каждые 10 сек + статистика каждую минуту |
| `judge.py` | ИИ-судья осмысленности: локальный OpenAI-совместимый сервер (llama.cpp + Qwen1.5-4B) |
| `corpus_gen.py` | Генерация языкового корпуса локальной моделью (для биграмм) |
| `libru_corpus.py` | Краулер lib.ru: реальный русский корпус (KOI8-R) |
| `wiki_corpus.py` / `ws_corpus.py` | Попытки корпуса из Wikipedia/Wikisource API (могут быть заблокированы) |
| `scorer.py` / `rank2.py` | Биграммный ранжир кандидатов по корпусу + финальный ИИ-судья |

Не входит в репозиторий (скачивается отдельно):
- `ru_50k.txt` — частотный список русских слов
  (FrequencyWords, OpenSubtitles 2018: `ru_50k.txt`);
- корпусы (`corpus.txt`, `corpus2.txt`), найденные кандидаты (`hits.txt`);
- GGUF-модель для судьи.

## Быстрый старт

```bash
# C++: одно слово в u64-числах
g++ -O3 -std=c++20 -pthread rs.cpp -o rscpp && ./rscpp

# NASM: 2 потока
nasm -f elf64 rs2.asm -o rs2.o && ld rs2.o -o rsasm2 && ./rsasm2

# Мультисловный поиск (нужен ru_50k.txt рядом)
g++ -O3 -std=c++20 -pthread ru.cpp -o ruwords && ./ruwords ru_50k.txt 160

# Строки произвольной длины
g++ -O3 -std=c++20 -pthread ru2.cpp -o ruwords2 && ./ruwords2 ru_50k.txt 160 60

# Ассемблерное ядро на словах 5+ букв
g++ -O2 -std=c++20 ru2dump.cpp -o ru2dump && ./ru2dump
nasm -f elf64 ru2asm.asm -o ru2asm.o && ld ru2asm.o -o ru2asm && ./ru2asm

# ИИ-судья (нужен локальный llama-server на 127.0.0.1:8817)
python3 judge.py 150 50
```

## Ограничения и наблюдения

- Вероятность встретить заданное слово длины L в числе из N цифр ≈ (N−L+1)·10⁻ᴸ;
  один «привет» (10 цифр) — это десятки секунд на C++/asm.
- Заданная фраза из двух слов — уже ~10⁻¹⁹ за попытку: на практике недостижимо.
  Поэтому мультисловный режим ищет не заданные слова, а любые словарные чтения.
- Длинные слова (5+ букв) кодируются 8-16 цифрами — их находок на порядки
  меньше, зато чтения чище.
- Смысл упирается не в объём, а в порядок слов: случайный поток даёт случайный
  порядок, а осмысленных порядков в языке ничтожно мало. Отсюда ИИ-судья и
  биграммный ранжир по реальному корпусу.

## 24-часовой прогон

```bash
nohup ./ruhunt ru_50k.txt 86400 > hunt_stdout.log 2>&1 &
tail -f hunt_journal.txt   # лучшая находка каждые 10 сек
tail -f hunt_stats.txt     # счётчики каждую минуту
````n
Ожидаемо за сутки при ~14 млн цифр/сек: ~1.2 трлн цифр, ~5.3 млрд двухсловных
чтений, ~10 млн фраз из 6+ слов, ~80 млн слов, склеенных на стыках чисел.
